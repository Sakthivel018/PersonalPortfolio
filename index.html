03 — HOW I THINK ABOUT IT

The model is one part of the system.

(the interesting part is what surrounds it)

I started with Python services, APIs, ETL, and document processing. That foundation now shapes how I build GenAI systems: the model is one part of a larger workflow that must ingest messy inputs and produce information a person or another service can use.

My work spans hybrid retrieval for long records, stateful LangGraph orchestration, schema-constrained extraction, deterministic validation, asynchronous processing, and human review. I focus on making the full path traceable and useful when the model is uncertain.
